# C7：核心系统全面复核

开始前读取项目状态、当前 ExecPlan、冻结模型和实验协议。先审查，不立即大改。

以四种角色审查：

1. 运筹优化/算法研究者；
2. 仿真与实验设计研究者；
3. Python 工程审查者；
4. 论文复现审查者。

检查：

- 数学模型、数据 Schema 和代码是否一致；
- 动态算法是否泄漏未来；
- 纵深阻挡和移位是否真实执行；
- 利用率和目标是否被错误解释；
- 批准求解器的状态、界、缩放或证明是否正确；
- 降级是否被完整记录；
- 指标是否来自统一日志；
- 随机种子和实验是否可复现；
- Windows 安装和路径；
- 测试缺口与性能瓶颈；
- 基线是否公平；
- 结论是否超过证据；
- `PROJECT_STATUS.md` 是否与实际一致。

先输出按严重度排序的问题、文件和行号。得到确认后分小批修复，每批运行测试。最终生成：

```text
docs/review/stage-c-review.md
docs/user/安装与运行.md
docs/user/复现实验.md
```

完成后停止，等待阶段 C 验收。
