# C1：环境、包结构、领域模型与输入校验

开始前读取 `AGENTS.md`、`PROJECT_STATUS.md`、当前 ExecPlan 和阶段 B 批准文档。前置阶段未通过或技术路线未冻结时停止。

只完成 C1，不进入 C2。

要求：

1. 根据阶段 B 创建 `pyproject.toml`、包结构和测试结构，并复核现有 `.gitignore`；
2. 使用 Python 3.11；
3. 只加入 C1 实际使用的依赖，说明用途、许可证和安装命令；
4. 建立阶段 B 批准的车辆、车位、纵深组、路网、分配和状态快照等领域对象；
5. 明确单位、枚举、ID 唯一性和校验错误；
6. 建立基础 CSV/JSON/YAML 读取与 Schema 校验；
7. 建立极小 fixture；
8. 不写仿真、核心优化或界面；
9. 运行格式、类型和测试检查；
10. 更新 ExecPlan并停止。

验收重点：

- 原始文件不被修改；
- 没有绝对路径和密钥；
- 普通与纵深车位定义符合阶段 B；
- 错误输入给出清楚提示；
- 安装和测试命令可在 Windows PowerShell 执行。
