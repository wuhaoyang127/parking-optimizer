# C6：批量实验、统计、可视化与报告

开始前读取项目状态、当前 ExecPlan和已经冻结的实验协议。只完成 C6，不进入 C7。

要求：

1. 建立配置驱动的实验运行器；
2. 严格使用阶段 B 冻结的场景、数据划分、随机种子、时间预算和统计方法；
3. 比较阶段 A/B 批准的所有基线、主算法和小规模基准；
4. 多随机种子重复；
5. 报告均值、标准差、置信区间、失败次数、降级次数和运行时间；
6. 不只输出综合分数；
7. 按冻结协议进行消融和敏感性分析；
8. 图表从保存的原始长表数据生成；
9. 保存 `run_id`、版本、配置、数据哈希、环境和硬件摘要；
10. 自动生成 Markdown 报告；
11. 保留主算法不如基线的场景；
12. 运行冒烟实验和至少一组完整小规模实验后停止。

完整实验耗时过长时，提供可复现命令和预计时间，不伪造结果。
