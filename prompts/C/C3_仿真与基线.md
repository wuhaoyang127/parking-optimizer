# C3：仿真/事件引擎、事件日志与基线

开始前读取项目状态、当前 ExecPlan 和阶段 B 批准文档。只完成 C3，不进入 C4。

要求：

1. 实现阶段 B 批准的离散事件或等价仿真机制；只有阶段 B 批准 SimPy 时才强制使用 SimPy；
2. 仿真器可以保存真值，策略只能接收批准的状态快照；
3. 实现统一事件日志，指标只能从日志或标准状态计算；
4. 实现阶段 A/B 批准的基线；
5. 明确无空位、不可达、阻挡无法释放和缓冲位不足的行为；
6. 增加手工时间线、占用冲突和未来信息泄漏测试；
7. 输出单场景可读日志和基础指标；
8. 不实现主优化算法；
9. 运行全部测试并停止。

验收必须证明：

- 同一物理位置不会被同时占用；
- 纵深阻挡和移位按模型真实执行；
- 移位次数与距离可追踪；
- 固定种子可复现；
- 策略没有访问未来真值。
