# M4：车主模式 React 前端

## 目标与用户可见结果

将已批准的 C 融合视觉方向落实为可运行的 React + TypeScript + Vite 车主端：电脑和手机均可
完成“找停车场 → 智能推荐 → 确认软锁/纵深风险 → 当前行程 → 动态重规划 → 停车/离场”的完整
流程。前端只消费 FastAPI v2 权威状态与路线，不复制算法、不伪造实时数据、不进入答辩模式 M5。

## 当前状态

- M1、M2、M3 已获用户批准，M3 标签为 `web-v2-m3-approved`；
- 当前里程碑为 M4，实施授权已开启；
- M1 高保真原型位于 `prototypes/web-v2/`，C 融合方向是视觉权威参考；
- M3 提供会话、Journey、动态重规划、仿真和 OpenAPI 契约；
- `apps/web/` 已完成正式 React 工程基线、P1 找停车场与 P2 智能停车/软锁页面；
- M5 答辩模式、自由实验台、伪 3D 和新算法不属于本阶段。

## 范围

### 包含

- React 19 + TypeScript 严格模式 + Vite 的 `apps/web/` 独立应用；
- 由 OpenAPI v2 生成或校验的前端 API 类型与单一请求客户端；
- 车主模式三个一级页面：找停车场、智能停车、当前行程；
- 电脑与手机完整同功能响应式布局；
- synthetic 来源、更新时间、加载、空数据、失败、离线和降级可见；
- 30 秒软锁、确认后预留、纵深知情确认、备选切换和等待恢复；
- 同一后端路线驱动地图高亮、文字指引和车辆显示插值；
- 偏航、推荐位被占、无法停入、停车完成、正常离场和演示重置；
- 固定可复现动画、组件测试、关键流程测试、Playwright 双视口验收和视觉截图；
- 本地 FastAPI + Vite 联调脚本与 M4 教学/交接材料。

### 不包含

- 答辩模式口令、研究证据页、算法选择器和自由实验台；
- 伪 3D、声音或 ParkSim 代码/素材集成；
- 新推荐算法、预测模型或真实停车场连接器；
- 账户、支付、真实地图、真实定位、数据库、Redis 或多 worker；
- M6 公网部署、离线安装包和 Safari/iPhone 实机最终承诺；
- 修改 v1、旧 Streamlit 页面或历史实验产物。

## 冻结架构

- 领域状态由后端 Journey/API 权威返回；前端只保留视图选择、抽屉开合和动画插值等 UI 状态；
- API 契约以 `schemas/v2/openapi.json` 为源，禁止手写第二套漂移 DTO；
- 车主界面不显示算法名称，统一称“智能推荐”；
- 区域示意图不使用真实地图，不绘制虚构道路；场内路线与文字指引来自同一后端 Route；
- 手机与电脑核心能力一致，响应式仅改变排列、密度与操作承载；
- 二维俯视是完整基线；动画结束不能自行把 Journey 改为 `OCCUPIED`；
- 轮询/重连只恢复服务端状态，不能延长软锁或预留；
- 前端依赖在 P0 审核许可证、Windows/现代浏览器兼容性与包体后锁定，不批量加入未使用库。

### P4 验收冻结（测量前）

- 真实浏览器联调不得拦截 `/api/v2/**`；FastAPI synthetic 与 Vite 由独立配置启动并健康等待；
- 四个停车场分别在 Edge 桌面与 Pixel 7 视口跑通推荐、预留、路线、至少一种异常及显式停入，
  异常类型可在四场景间分摊；另以 Chrome 桌面运行真实 smoke；
- 推荐、纵深确认、导航、异常/终态至少各保存桌面和手机证据，manifest 记录 commit、视口、浏览器、
  synthetic/真实 API、场景和时间；
- 测量环境记录 Windows、CPU、RAM、浏览器、commit、loopback 与生产构建；暖启动 5 次主标题可见
  p95 不超过 2.0 秒，10 次 mutation 到权威新状态可见 p95 不超过 1.0 秒（重规划/失败不超过 2.0 秒）；
  路线动画前台采样 5 秒，rAF 间隔 p95 不超过 50ms 且大于 100ms 的长帧为 0；
- 初始生产 JS+CSS gzip 合计不超过 400 KiB；桌面/手机横向溢出不超过 1px；全部原始样本保留，
  不得在看到结果后放宽阈值。

## 验收矩阵

- 找停车场：四个 synthetic 场景均可搜索、查看详情并进入推荐；
- 智能停车：普通/充电、无位等待、主位/备选、纵深接受/拒绝行为与 API 一致；
- 当前行程：期限不续期、偏航重规划、外部占位、停车、离场和重置可复现；
- 真实性：synthetic、管理层路线和原型边界在关键页面可见；
- 隔离：前端不暴露答辩能力，不共享或修改 defense 状态；
- 响应式：目标桌面和手机视口功能一致，无横向溢出、遮挡或不可操作控件；
- 工程：类型生成、lint、测试、生产构建和后端 Web v2 回归全部通过。

## 风险与降级

- Node/npm 不可用：先使用仓库配置的 Node 运行时；安装前报告版本与依赖方案；
- OpenAPI 类型工具增加过多依赖：优先选择单用途生成器并提交生成结果与漂移检查；
- 地图实现诱导真实导航：继续使用 SVG/HTML 区域示意图和后端场内路网，不接第三方地图；
- 动画影响低端设备：保留二维简化显示和降低非关键动画密度，不删除核心状态反馈；
- 后端不可达：展示明确离线页与重试，不用本地随机数据静默冒充 API；
- M3 单进程限制：M4 只按本地/单进程演示原型接入，不声称生产并发。
