## 参考与设计选择

参考 Mapbox 官方 navigation UX 的“出发前路线预览 + 路线和文字指引”分层，以及 OpenIndoorMaps
的设施内分层地图方向；只借鉴信息层次和路线可读性，不复制代码/视觉资产，不新增依赖。
来源：https://docs.mapbox.com/help/getting-started/navigation/ 、
https://github.com/openindoormaps/openindoormaps 。

本轮以清晰的白色路线边界、蓝绿主路线、起终点标记、当前步骤提示改善读图；布局几何和方向
由后端 Route/已发布设施布局提供。动画仍是管理层 UI 插值，不能称实时定位或车辆控制。
