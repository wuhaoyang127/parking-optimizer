## 2. 阶段B需要冻结的核心定义

### 2.1 停车场模型

阶段B必须给出精确定义：

- [ ] **路网模型**：
  - 节点类型（ENTRY, EXIT, ROAD_NODE, PARKING_SPOT, BUFFER_SPOT）
  - 边类型与权重（距离/时间/转弯惩罚）
  - 有向/无向
  - JSON Schema

- [ ] **车位模型**：
  - 普通独立车位：`{spot_id, type=STANDALONE, position, stack_group_id=unique, depth=1}`
  - 纵深车位：`{spot_id, type=TANDEM, position, stack_group_id, depth}`
  - 缓冲位：`{spot_id, type=BUFFER, position}`

- [ ] **阻挡定义**：
  - 形式化条件：`blocked(spot_a, spot_b) ⇔ stack_group_id相同 ∧ depth(spot_a) < depth(spot_b) ∧ spot_a被占用 ∧ spot_b需要驶出`
  - 多级阻挡：A挡B挡C → A移出后B才能移出后C才能驶出

- [ ] **移位操作**：
  - 一次移位 = (阻挡车辆, 起点车位, 终点车位, 路径距离, 时间)
  - 缓冲位状态机：空闲→被移位车占用→归位或保留
  - 连锁移位处理规则

### 2.2 需求模型

- [ ] **车辆需求数据字段**：
  - `vehicle_id`, `arrival_time`, `departure_time` (真实离场), `parking_duration`
  - 可选：`estimated_departure` (预计离场时间)
  - JSON Schema

- [ ] **仿真需求生成规则**：
  - 到达分布：双峰（上午+下午高峰）
  - 停车时长分布：需要指定分布类型和参数
  - 负载水平：低(≤80辆/天), 中(≈150), 高(≥220)

### 2.3 目标函数与指标

阶段B必须冻结所有指标的计算公式：

- [ ] **主要指标**：
  1. 需求满足率 = 成功分配车辆数 / 总到达车辆数
  2. 车位时空利用率 = ∑(每车位被占用时间) / (总车位数 × 仿真时长)
  3. 有效车位时空利用率 = 排除因阻挡而不可用的时间
  4. 总移位次数、总移位距离
  5. 平均等待时间、总行驶距离

- [ ] **目标优先级**（建议分层词典序）：
  1. 最大化需求满足率（硬：必须满足尽可能多的需求）
  2. 最大化有效时空利用率
  3. 最小化移位次数与距离
  4. 最小化等待时间与行驶距离

- [ ] **仿真聚合层次**：单车、单场景、多种子平均

### 2.4 信息边界

- [ ] **离线 oracle 可见**：全部车辆到达时间、停车时长、离场时间
- [ ] **在线贪心可见**：当前停车场状态 + 当前到达车辆信息 + （可选）预计离场
- [ ] **禁止泄露给在线算法**：未来车辆到达、真实停车时长、未来最优分配

### 2.5 决策触发机制

- [ ] **触发方式**：车辆到达时触发（事件驱动）
- [ ] **可选定时触发**：每隔N分钟全局重优化（阶段C评估是否加入）

## 3. 阶段B需要完成的工程设计

### 3.1 软件架构

- [ ] **包结构** (`src/parking_opt/`)：
  ```
  parking_opt/
  ├── domain/          # 领域模型：Spot, Vehicle, StackGroup, RoadNetwork
  ├── routing/         # 路网与路径：NetworkX 封装
  ├── simulation/      # SimPy 仿真：arrival, allocation, blocking, relocation, departure
  ├── strategies/      # 分配策略：greedy, dijkstra_sa, fcfs, nearest, random
  ├── evaluation/      # 指标计算
  ├── io/              # 数据读写：JSON schema, 验证
  └── cli/             # 命令行入口
  ```

- [ ] **数据流**：
  ```
  路网JSON + 需求JSON → 仿真引擎 → 策略(在线) → 事件日志 → 指标计算 → 报告
  路网JSON + 需求JSON → CP-SAT(离线) → 离线基准指标
  ```

### 3.2 需要建立的依赖

- [ ] `pyproject.toml`：Python 3.11, NetworkX, SimPy, OR-Tools, pytest, Streamlit(暂不装)
- [ ] 虚拟环境 + 安装说明

### 3.3 测试计划

- [ ] 单元测试：路网可达性、车位占用不重叠、阻挡判断、缓冲位状态机、信息泄漏检查
- [ ] 集成测试：极小人工例端到端（5车位10车）
- [ ] 正确性测试：CP-SAT 在小规模上与手算结果一致

### 3.4 实验协议

- [ ] **场景矩阵**：纵深比例(0%,30%,50%,70%) × 负载(低,中,高) = 12种场景
- [ ] **种子**：每种≥5个随机种子 → ≥60次独立运行
- [ ] **比较对象**：贪心, SA, FCFS, 最近路径, 随机, 离场顺序贪心 = 6种策略
- [ ] **统计报告**：均值±标准差, 配对比较, 效应量
- [ ] **图表**：场景-指标热力图, 收敛曲线(SA), 移位事件时序图
