# 05 最终路线决策

## 一句话路线定义

> **路网成本预处理 + 离散事件仿真 + CP-SAT小规模离线基准 + 带缓冲位的在线贪心策略（主方法）+ 确定性降级，辅以 Dijkstra-SA 作为对照基线。**

---

## 1. 核心研究问题

在普通独立车位与纵深车位混合的停车场中，车辆陆续实时到达，系统需在有限信息下为每辆车分配车位，使得：
- **主目标**：最大化有效车位时空利用率（需求满足率）
- **次目标**：最小化移位次数与移位距离
- **再次目标**：减少等待时间与行驶距离

核心挑战：**纵深阻挡导致的车位不可用与移位操作如何被精确建模和有效规避**。

---

## 2. 系统边界

| 包含 | 不包含 |
|---|---|
| 停车场路网建模（入口/道路节点/车位节点/边权重） | 真实车辆感知、转向控制、碰撞规避 |
| 普通车位与纵深车位统一表示（stack_group_id + depth） | 自动驾驶轨迹跟踪 (Hybrid A\*) |
| 车辆实时到达、分配、入位、阻挡、移位、离场的全流程仿真 | 停车场外道路网络 |
| 多种分配策略的比较 | 定价或市场机制 |
| CLI/Streamlit 展示系统 | 真实车辆调度命令执行 |

---

## 3. 四层算法架构

```
┌─────────────────────────────────────────────┐
│              第0层：离线基准                   │
│  CP-SAT 小规模全信息最优 → 定义性能上界        │
├─────────────────────────────────────────────┤
│              第1层：动态主方法                  │
│  在线贪心 + 缓冲位策略                         │
│  （可选增强：滚动时域CP-SAT → 阶段C进阶）       │
├─────────────────────────────────────────────┤
│              第2层：对照基线                    │
│  Dijkstra-SA 元启发式（已有代码）               │
│  FCFS / 最近路径 / 随机 / 离场顺序贪心          │
│  多基线公平比较                                │
├─────────────────────────────────────────────┤
│              第3层：降级安全网                  │
│  主方法超时/不可行 → 规则降级                   │
│  降级规则：FCFS + 优先独立车位 + 无缓冲位       │
└─────────────────────────────────────────────┘
```

### 第0层：CP-SAT 离线基准（小规模）
- **用途**：证明"离最优有多远"
- **规模限制**：在10-20个车位、20-40辆车的规模下求解全信息最优分配
- **工具**：Google OR-Tools CP-SAT
- **产出**：给出次优方法（贪心、SA）相对于最优的 gap

### 第1层：在线贪心 + 缓冲位策略（主方法）
- **触发**：每辆车到达时
- **决策规则（优先级递减）**：
  1. 有空闲独立车位 → 分配最近（Dijkstra距离）的独立车位
  2. 有空闲纵深 depth=1 车位 → 分配等待/行驶综合代价最小的
  3. 仅有 depth>1 车位可用 → 分配预计离场时间最早的内侧车辆所阻挡的车位
  4. 无任何空位 → 检查缓冲位可用性 → 等待或拒绝
- **缓冲位机制**：
  - **动态缓冲位**：无专用缓冲位，可临时征用任意空闲普通车位作为缓冲位
  - 当被阻挡车辆需离场时：阻挡车→征用空车位为缓冲位→被阻挡车驶离→阻挡车归位→释放缓冲位
  - 征用和释放事件记录在日志中
- **不依赖未来信息**：仅在可选时使用"预计离场时间"（若有），否则使用历史平均停车时长

### 第2层：Dijkstra-SA（对照基线）
- 改造已有代码为在线/批次触发
- 作为元启发式对照，展示主方法相对于SA的优劣
- 其他基线：FCFS、最近路径分配、随机分配、离场顺序贪心

### 第3层：降级安全网
- 如果主方法逻辑判断复杂度过高或状态异常 → 降级为简单 FCFS（先到先服务，优先独立车位）
- 所有降级事件记录在日志中，不静默降级

---

## 4. 为什么不选其他路线

| 路线 | 不选/降级理由 |
|---|---|
| **GA/PSO/ACO** | 不提供相对于SA的根本优势；编码复杂；实现工作量大 |
| **纯CP-SAT离线** | 不处理动态到达；大规模超时；保留为离线基准（第0层） |
| **纯滚动时域CP-SAT** | 价值高但实现复杂度超出大创项目本科组员当前能力；保留为阶段C进阶选项（若贪心效果不理想） |
| **强化学习** | 训练数据需求大、训练周期长、解释性差、失败风险极高、答辩困难 |
| **预测+优化** | 需要真实历史数据；当前无数据；保留为论文"未来工作"讨论 |
| **ARIMA-SA/ACO/RF** | 已在M1中详细否定（时间尺度错位/RF不是优化器/概念错误） |

## 5. 纵深车位统一建模

本项目将**普通车位和纵深车位的管理与优化统一为一个模型**：

| 概念 | 表示 | 普通车位 | 纵深车位（深度>1） |
|---|---|---|---|
| 车位组 | `stack_group_id` | 每个独立车位自成一组 | 同一纵深列的车位共享 group_id |
| 深度 | `depth` | depth=1 | depth=1（靠通道）~最大深度 |
| 空闲 | `is_occupied=False` | 直接可分配 | depth=1 可分配；depth>1 要求外侧全空闲 |
| 阻挡 | 外侧 depth<自己的车位被占用 | 永不发生 | depth>1 时可能发生 |
| 移位 | 阻挡车移入缓冲位→被阻挡车驶出→归位 | 永不发生 | 阻挡发生时触发 |

这样普通独立车位就是 `stack_group_id=unique, depth=1` 的特例——所有算法逻辑自动统一处理。

## 6. 是否需要预测

**用户决定：暂不引入预测模块。**

贪心策略使用历史平均停车时长做估计，阶段C在仿真中评估预测对效果的敏感度，作为论文讨论点。

阶段B中保留 `estimated_departure` 作为可选字段，当前默认用历史均值填充。

## 7. 核心决策周期与降级策略

### 正常决策流程
```
车辆到达(t) → 更新停车场状态
  → 判断：有空位？
    ├─ 是 → 贪心选择最优车位 → 分配 → 仿真入位
    └─ 否 → 检查缓冲位/等待队列
         ├─ 可等待 → 等待队列
         └─ 不可等待 → 拒绝（记录未满足）
```

### 降级触发条件
- 主方法计算时间 > 1秒
- 主方法返回不可行解
- 路网数据不完整
- 仿真状态异常

### 降级策略
- 降为 FCFS + 优先独立车位
- 记录降级事件（时间、原因、替代方案）
- 结果中单独标注降级案例

## 8. 与申请书目标的连续性

虽然否定了 ARIMA-SA/ACO/RF 和"由内到外顺序停放"简化假设，但调整后的路线**完全服务于立项目标**：

| 立项目标 | 本路线的实现方式 |
|---|---|
| 降低移位频率 | 贪心策略显式规避阻挡；缓冲位机制减少必要移位 |
| 提高车位利用率 | 统一建模+动态分配，最大化时空利用率 |
| 整合路径规划与供需匹配 | Dijkstra路网+实时分配决策 |
| 形成可验证可展示系统 | 仿真器+多基线对比+可视化 |

**立项目标不变，算法路线优化了。**

## 10. 最终路线总结

| 事项 | 决定 |
|---|---|
| **主方法** | 在线贪心分配 + 缓冲位移位策略 |
| **离线基准** | CP-SAT 小规模精确优化（10-20车位） |
| **对照基线** | Dijkstra-SA（已有代码改造）+ FCFS + 最近路径 + 随机 |
| **降级策略** | FCFS + 优先独立车位（规则安全网） |
| **缓冲位** | 动态征用空闲车位（无专用缓冲位） |
| **预测** | 暂不引入，用历史均值估计 |
| **交付形式** | 向管理员推荐方案的 Dashboard（Streamlit） |
| **路网工具** | NetworkX（替代手写Dijkstra） |
| **仿真工具** | SimPy 离散事件仿真 |
| **精度基准工具** | OR-Tools CP-SAT |
| **进阶选项（阶段C评估）** | 滚动时域CP-SAT（若贪心效果不够好） |
| **明确不采用** | ARIMA、RF（优化）、RL、GA/PSO/ACO、预测+优化 |

### 三个最重要的否定结论
1. ARIMA + 优化器的串行架构在所有路线中都不可行（缺乏数据、时间尺度不匹配）
2. 随机森林是预测模型，不能用作组合优化求解器
3. 申请书"由内到外顺序停放"的简化假设消解了优化问题本身——无选择即无优化

### 三个最大风险
1. 贪心策略在复杂场景下可能显著劣于离线最优（gap大），需要在阶段C通过实验验证
2. 缓冲位数量对效果敏感——太少无法有效移位，太多浪费容量，需在阶段B用最小规模验证
3. 若贪心效果不佳，回退到滚动时域CP-SAT的复杂度可能导致阶段C/D延期
