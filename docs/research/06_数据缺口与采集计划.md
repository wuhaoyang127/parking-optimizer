# 06 数据缺口与采集计划

## 1. 当前已有数据

| 数据项 | 格式 | 来源 | 状态 |
|---|---|---|---|
| 停车场平面图 | 图像/PDF | 实地获取或设计图 | ✅ 已有 |
| 车位坐标 | 待提取 | 从平面图测量 | ⚠️ 待数字化 |

## 2. 当前缺少数据

### 2.1 核心缺失（影响模型可行性）

| 数据项 | 重要性 | 当前替代方案 | 真实采集难度 |
|---|---|---|---|
| 车辆到达时间序列（含时间戳） | **致命级** | 仿真生成（双峰分布） | 需摄像头/地感/闸机记录，可商量获取 |
| 车辆停车时长 | **致命级** | 仿真生成（40min-6h） | 同上，入场-出场时间差 |
| 实际阻挡/移位事件记录 | **严重级** | 仿真中自动产生 | 需人工标注或传感器，采集难度高 |
| 高峰/平峰时段分布 | **严重级** | 假设参数（72%高峰） | 统计闸机记录可得，难度低 |
| 预约/预计离场信息 | **次级** | 可选：设为已知（oracle）或未知（现实） | 需用户端开发 |

### 2.2 次要缺失（影响实验可信度）

| 数据项 | 重要性 | 替代方案 |
|---|---|---|
| 车辆类型（小型/中型/大型） | 低 | 所有车辆统一尺寸 |
| 不同天气/工作日/节假日的需求分布 | 低 | 仿真分场景生成 |
| 特殊车辆（残疾人/充电）需求 | 低 | 暂不建模 |
| 车主步行偏好（多远愿意走） | 低 | 步行距离不作为目标 |

## 3. 分级验证方案

### 第1级：极小人工可手算例（≤5车位，≤10辆车）

**目的**：验证模型逻辑正确性，证明算法没有根本性错误。

| 参数 | 值 |
|---|---|
| 车位 | 2独立 + 1纵深组(2深度) = 4车位 |
| 车辆 | 5辆（含2辆同时到达、1辆阻挡场景） |
| 验证方式 | 手动计算最优分配 → 对比每个算法输出 |
| 预期产出 | 确认贪心、SA、CP-SAT在三者上的行为是否符合预期 |

**结论可成立的范围**：模型逻辑正确→可信任仿真结果中的逻辑部分。

### 第2级：仿真数据验证（100车位，多场景多种子）

**目的**：在受控仿真环境中证明动态贪心策略全面优于基线。

| 参数 | 值 |
|---|---|
| 停车场布局 | 从平面图建模，~100停车位，含纵深组 |
| 车辆需求 | 仿真生成：双峰到达分布，多种负载(低80/中150/高220辆/天) |
| 纵深比例 | 0%(全独立), 30%, 50%, 70% 纵深四种场景 |
| 种子数 | 每种场景≥5个随机种子 |
| 比较对象 | 贪心(vs) FCFS、最近路径、Dijkstra-SA、离场顺序贪心 |
| 指标 | 满足率、时空利用率、移位次数/距离、等待时间、行驶距离 |
| 统计方法 | 多种子均值和标准差；配对检验或效应量 |

**结论可成立的范围**：
- ✅ 可以声称："在所设仿真场景中，贪心策略在XX指标上平均优于基线XX%"
- ❌ 不能声称："在真实停车场必然提高XX%"

### 第3级：真实数据验证（后续，本项目可能不完）

| 数据需求 | 采集方法 | 瓶颈 |
|---|---|---|
| 连续1-2周闸机记录（入场/出场时间戳） | 与停车场管理方协商数据导出 | 隐私审批、格式兼容 |
| 移位/阻挡记录 | 仿真回放+人工标注，或传感器 | 采集成本高 |
| 预约数据 | 若有已运行的预约系统则导出 | 多数停车场无此功能 |

**结论可成立的范围**：
- 若有真实数据 ✅："在XX停车场X周数据上的回放仿真中，贪心策略..."
- 若无真实数据 ✅："在基于真实布局的仿真中..."（需如实说明）

## 4. 当前阶段的结论边界

### 可以成立（仿真验证后）
- 模型逻辑可实现且正确
- 在给定仿真设定下，方法A优于方法B（限定场景、指标、种子）
- 系统留有真实数据接口，可接入未来数据

### 不能成立
- 在真实停车场必然提高某个百分比
- 在所有场景和指标上优于所有方法
- 仿真中的需求分布等同于真实规律
- 已具备真实车辆控制能力

## 5. 真实数据采集计划（如条件允许）

| 步骤 | 内容 | 时间估计 |
|---|---|---|
| 1 | 联系停车场管理方，说明学术用途，签署数据使用协议 | 1-2周 |
| 2 | 导出闸机入场/出场记录（CSV/Excel），脱敏处理 | 1天 |
| 3 | 提取到达时间序列和停车时长分布 | 1-2天 |
| 4 | 与仿真中的假设分布对比，校准参数 | 1-2天 |
| 5 | 在真实到达序列上回放仿真，比较策略 | 1周 |

**降级方案**：若无法获取真实数据，整个项目完全基于仿真验证，但在论文和答辩中必须明确说明。这不影响项目完成——仿真验证在本科大创中是完全可以接受的。
