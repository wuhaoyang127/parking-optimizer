# 02 文献检索方法

## 检索策略

### 检索主题（9个方向）
按阶段A提示词要求，覆盖以下检索方向：

| # | 主题 | 英文检索词 |
|---|---|---|
| 1 | 动态停车位分配 | dynamic parking allocation / assignment |
| 2 | 滚动时域/模型预测停车调度 | rolling horizon parking / model predictive parking assignment |
| 3 | 自主代客泊车车位分配 | autonomous valet parking slot assignment |
| 4 | 纵深/堆叠车位移位优化 | stacked/tandem parking relocation optimization |
| 5 | 共享停车供需匹配 | shared parking supply-demand matching |
| 6 | 离散事件停车仿真 | discrete-event parking simulation |
| 7 | 精确整数/约束规划求解分配与调度 | exact integer/constraint programming for assignment and scheduling |
| 8 | 在线停车分配 | online parking assignment |
| 9 | 停车利用率与移位指标 | parking utilization and relocation metrics |

### 优先来源层级
1. **第一优先**：IEEE Transactions on Intelligent Transportation Systems、Transportation Research Part B/C/E、European Journal of Operational Research、Transportation Science
2. **第二优先**：其他高水平期刊/会议（IEEE ITSC、TRB Annual Meeting、INFORMS）
3. **第三优先**：高引用学位论文、作者公开代码仓库、OR-Tools/SimPy 官方文档
4. **补充**：奠基性文献（不限年限）

### 筛选标准
- 近十年（2015-2025）优先，保留少量早年奠基文献
- 有公开代码或详细伪代码者加权
- 与"普通+纵深混合车位"场景相关者加权
- 排除纯硬件/传感器/通信协议论文

### 证据等级标注
每条文献标注证据等级：

| 等级 | 含义 |
|---|---|
| **A** | 获取全文并核实关键结论 |
| **B** | 已读摘要，结论基于摘要推断 |
| **C** | 基于模型训练数据记忆，标题/作者/期刊置信度高，请用户验证 |
| **D** | 间接引用或其他来源提及，待获取原文 |
