# 02 验收标准

---

## 1. 正确性验收

| # | 测试 | 通过条件 |
|---|---|---|
| T1 | 路网可达性 | 所有车位从 ENTRY 可达 |
| T2 | 车位占用不重叠 | 任意时刻每车位最多 1 辆车 |
| T3 | 阻挡判断 | 极小例手动验证阻挡检测正确 |
| T4 | 缓冲位状态机 | FREE→RESERVED→OCCUPIED→FREE 转换合法 |
| T5 | 信息泄漏 | 在线策略不能访问 parking_duration 真实值 |
| T6 | 可复现性 | 固定种子产生完全相同的指标 |
| T7 | CP-SAT vs 手算 | 极小例中 CP-SAT 结果与手算一致 |
| T8 | 降级触发 | 制造超时场景确认降级逻辑正确 |

---

## 2. 性能验收

| # | 指标 | 阈值 |
|---|---|---|
| P1 | 贪心单次决策时间 | < 0.01s |
| P2 | SA 3000迭代(100车位) | < 60s |
| P3 | CP-SAT 小规模(20车位) | < 300s |
| P4 | 全仿真(86400s, 150车) | < 120s |

---

## 3. 效果验收（仿真中）

| # | 条件 | 最低要求 |
|---|---|---|
| E1 | 中负载+30%纵深 | 贪心满足率 ≥ FCFS |
| E2 | 中负载+50%纵深 | 贪心移位次数 < 最近路径 |
| E3 | 小规模 | 贪心满足率 ≥ CP-SAT最优的 90% |
| E4 | 任意场景 | 贪心不能产生比随机更差的满足率 |
| E5 | 降级场景 | 降级后系统仍返回结果（不崩溃） |

**⚠️ 不预设具体提升百分比。E1-E5 是方向性验收，不要求数值上的统计显著性。**
