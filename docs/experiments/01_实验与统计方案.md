# 01 实验与统计方案

---

## 1. 实验矩阵

| 维度 | 水平 | 数量 |
|---|---|---|
| 纵深比例 | 0%, 30%, 50%, 70% | 4 |
| 负载水平 | 低(80辆/天), 中(150辆/天), 高(220辆/天) | 3 |
| **场景合计** | | **12** |

### 额外场景
- 全部纵深的极端场景（100%纵深，中负载）：1 场景
- 波动场景（突发高峰）：1 场景

---

## 2. 随机种子

每种场景 ≥5 个独立随机种子 → **≥70 次独立运行**

种子控制：车辆到达时间序列、停车时长分配。

## 4. 评估指标（已冻结）

| 指标 | 聚合方式 |
|---|---|
| 需求满足率 | 均值 ± 标准差 |
| 车位时空利用率 | 均值 ± 标准差 |
| 有效利用率 | 均值 ± 标准差 |
| 移位次数 | 均值 ± 标准差 |
| 移位距离(m) | 均值 ± 标准差 |
| 平均等待时间(s) | 均值 ± 标准差 |
| 总行驶距离(m) | 均值 ± 标准差 |
| 降级事件数 | 计数 |

---

## 5. 统计方法

- **描述统计**：均值、标准差、中位数、Q1、Q3
- **主方法 vs 每个基线**：配对 t 检验（配对依据：相同种子+场景）
- **效应量**：Cohen's d
- **显著性水平**：α = 0.05
- **图表**：
  - 场景-指标热力图（6策略 × 12场景）
  - SA 收敛曲线样例
  - 移位事件时序图
  - 贪心 vs CP-SAT 的 gap 散点图（小规模）

---

## 6. 消融实验

| 消融项 | 方法 |
|---|---|
| 优先级贡献 | 主方法去掉某一优先级（如去掉 depth=1 优先）vs 完整主方法 |
| 缓冲位影响 | 禁用缓冲位 vs 动态缓冲位 |
| 估计精度影响 | 历史均值 vs 真实值(oracle) |
