# 启动包完整性检查

正式执行阶段 A 前确认：

- [ ] 项目根目录名为 `parking-optimizer`；
- [ ] `AGENTS.md`、`PROJECT_STATUS.md`、`.agent/PLANS.md` 存在；
- [ ] `PROJECT_STATUS.md` 的 `next_prompt` 指向存在的文件；
- [ ] `current_exec_plan` 和 `latest_handoff` 为 `null` 时按规则跳过；
- [ ] `current_stage_blockers` 是单行 JSON 字符串数组；
- [ ] `downstream_blockers` 是单行 JSON 对象数组，每项包含 `target_stage` 和 `issue`；
- [ ] 初始 `current_stage_blockers` 为空，阶段 A 可以开始；
- [ ] 两份原始 Word 位于 `references/original/`；
- [ ] 已在 Git 初始化前运行 `python scripts/validate_starter_package.py --initial`；
- [ ] 已使用 `git init -b main` 初始化 Git；
- [ ] 当前分支为 `stage-a-research`；
- [ ] `PROJECT_STATUS.md` 已更新为真实 Git 状态；
- [ ] 已运行 `python scripts/validate_starter_package.py`，且没有分支不一致；
- [ ] 默认检查前后 Git 工作区没有新增报告修改；
- [ ] `docs/候选算法路线.md` 标记为 candidate；
- [ ] 阶段 B 提示词未预设 CP-SAT、滚动时域或其他具体方法；
- [ ] C1—C7 被视为阶段 B 后需要复核的通用模板；
- [ ] 交互展示框架留待 D0 复核，Streamlit 只是暂定偏好；
- [ ] `.gitignore` 已生效；
- [ ] 没有 `.env`、密钥、真实个人数据或运行产物进入 Git；
- [ ] 新对话先读取状态文件，不依赖旧聊天记录。

检查模式：

```powershell
# 刚解压、尚未初始化 Git
python scripts/validate_starter_package.py --initial

# Git 项目持续检查
python scripts/validate_starter_package.py

# 只有明确需要保存快照时才写报告
python scripts/validate_starter_package.py --write-report
```

默认检查只读，文件统计排除 `.git`、虚拟环境、缓存、输出和被忽略数据。
该脚本只验证启动包结构和一致性，不证明未来算法、数学模型或实验结果正确。
