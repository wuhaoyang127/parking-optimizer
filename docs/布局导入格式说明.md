# 自定义停车场布局 JSON 格式说明

上传一个 JSON 文件来定义你自己的停车场布局，导入后可在仿真配置中选用。

---

## 最简示例

```json
{
  "name": "我的停车场",
  "nodes": [
    { "id": "ENTRY", "type": "entry", "x": 0, "y": 0 },
    { "id": "R1",    "type": "road",  "x": 5, "y": 0 },
    { "id": "S01",   "type": "spot",  "x": 8, "y": 3, "spot_type": "standalone" },
    { "id": "T1-1",  "type": "spot",  "x": 8, "y": -3, "spot_type": "tandem", "group": "T1", "depth": 1 },
    { "id": "T1-2",  "type": "spot",  "x": 11, "y": -3, "spot_type": "tandem", "group": "T1", "depth": 2 }
  ],
  "edges": [
    { "from": "ENTRY", "to": "R1",  "distance": 5 },
    { "from": "R1",    "to": "S01", "distance": 3 },
    { "from": "S01",   "to": "R1",  "distance": 3 },
    { "from": "R1",    "to": "T1-1","distance": 3 },
    { "from": "T1-1",  "to": "T1-2","distance": 3 },
    { "from": "T1-2",  "to": "T1-1","distance": 3 },
    { "from": "T1-1",  "to": "R1",  "distance": 3 },
    { "from": "R1",    "to": "ENTRY","distance": 5 }
  ]
}
```

---

## 字段说明

### 顶层

| 字段 | 必填 | 类型 | 说明 |
|------|:--:|------|------|
| `name` | ✅ | string | 布局名称，显示在下拉选项中 |
| `nodes` | ✅ | array | 节点列表 |
| `edges` | ✅ | array | 边列表（**双向都要写**） |

### 节点 (nodes)

| 字段 | 必填 | 类型 | 说明 |
|------|:--:|------|------|
| `id` | ✅ | string | 唯一标识；**至少一个 `type="entry"` 的节点**；可多个入口/出口，命名任意（`ENTRY`/`EXIT` 优先作为默认口） |
| `type` | ✅ | string | `"entry"`（入口） / `"exit"`（出口） / `"road"` / `"spot"` |
| `x` | ✅ | number | X 坐标（米） |
| `y` | ✅ | number | Y 坐标（米） |
| `spot_type` | ⚠️ | string | **仅 type="spot" 时需要**：`"standalone"`（独立）或 `"tandem"`（纵深） |
| `group` | ⚠️ | string | **仅 tandem 时需要**：同一组纵深车位用相同的 group 名 |
| `depth` | ⚠️ | number | **仅 tandem 时需要**：纵深位置，1=外侧，2=内侧 |

### 边 (edges)

| 字段 | 必填 | 类型 | 说明 |
|------|:--:|------|------|
| `from` | ✅ | string | 起点节点 ID |
| `to` | ✅ | string | 终点节点 ID |
| `distance` | ✅ | number | 路径长度（米），可用坐标距离 |

---

## 注意事项

1. **边必须双向写**：如果 R1 能到 S01，S01 也要能回到 R1（两条边）
2. **至少一个入口**：所有车辆从 `type="entry"` 的节点进入；车辆需求可指定 `entry_id`（未指定走默认入口：优先 `ENTRY`，否则第一个入口）
3. **出口可选**：有 `type="exit"` 节点时，车辆可指定 `exit_id` 离场（未指定走默认出口：优先 `EXIT`，否则第一个出口）；没有出口节点时离场回该车入口
4. **Tandem 成对出现**：每个 group 必须有 depth=1 和 depth=2 各一个，depth=1 靠近道路
5. **坐标用米**：建议间距 3-5 米，和真实停车场比例一致
6. **一个 json 只能定义一个布局**，导入后会追加到布局列表

### 多入口多出口示例（节选）

```json
{
  "nodes": [
    { "id": "ENTRY", "type": "entry", "x": 0, "y": 0 },
    { "id": "ENTRY_2", "type": "entry", "x": 100, "y": 0 },
    { "id": "EXIT", "type": "exit", "x": 0, "y": 60 },
    { "id": "EXIT_2", "type": "exit", "x": 100, "y": 60 },
    { "id": "S01", "type": "spot", "x": 8, "y": 3, "spot_type": "standalone" }
  ],
  "edges": [
    { "from": "ENTRY", "to": "S01", "distance": 8 },
    { "from": "S01", "to": "EXIT", "distance": 8 },
    { "from": "S01", "to": "ENTRY", "distance": 8 },
    { "from": "EXIT", "to": "S01", "distance": 8 }
  ]
}
```

> 入口/出口的**随机分配**：当布局有 ≥2 个入口（或出口）时，仿真生成的需求会按
> 随机种子为每辆车**独立**分配入口与出口（等概率，可复现）；只有一个口时全部走该口。
