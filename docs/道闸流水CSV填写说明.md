# 道闸流水 CSV 填写说明（给停车场运营方）

> 用途：停车场把**车牌识别 + 道闸进出记录**导出成 CSV，交给系统做真实数据仿真验证。
> 系统只**读取**数据用于算法验证，不会反向控制任何设备；车牌默认**脱敏**处理，原始车牌不落库。

---

## 一、一句话说明

导出一个 CSV 文件，每一行是「一辆车的一次完整进出记录」：什么车、什么时候进、什么时候出、从哪个口进、从哪个口出。

## 二、列名要求

**必填 3 列，选填 2 列**，列名中英文都可以（见括号内的别名）：

| 列 | 必填 | 中文列名 | 英文列名 | 说明 |
|---|---|---|---|---|
| 车牌 | ✅ | `车牌` / `车牌号` | `plate` / `plate_no` | 系统默认脱敏后使用 |
| 入场时间 | ✅ | `入场时间` / `进场时间` | `entry_time` / `in_time` | 见下方时间格式 |
| 出场时间 | ✅ | `出场时间` / `离场时间` | `exit_time` / `out_time` | 必须晚于入场时间 |
| 入口编号 | ⭕ | `入口` / `入口编号` | `entry_id` | 对应平面图上的入口，可不填 |
| 出口编号 | ⭕ | `出口` / `出口编号` | `exit_id` | 对应平面图上的出口，可不填 |

## 三、时间格式（二选一）

1. **日期时间**（推荐，人看得懂）：
   - `2026-08-30 08:00:00`
   - `2026-08-30T08:00:00`（T 分隔也可以）
   - `2026/08/30 08:00`（到分钟也可以）
2. **Unix 时间戳**（秒）：`1753843200`

同一文件里两种格式混用也可以，系统会自动识别。

## 四、完整示例

直接复制下面内容存成 `道闸流水.csv` 就能用（项目里也附了示例文件 `data/samples/道闸流水示例.csv`）：

```csv
车牌,入场时间,出场时间,入口,出口
京A12345,2026-08-30 08:00:00,2026-08-30 09:30:00,entry_1,exit_1
京B67890,2026-08-30 08:05:00,2026-08-30 08:35:00,entry_1,exit_1
沪C11111,2026-08-30 08:12:00,2026-08-30 10:05:00,entry_1,exit_1
粤D22222,2026-08-30 09:00:00,2026-08-30 09:50:00,entry_1,exit_1
京E33333,2026-08-30 09:15:00,2026-08-30 11:20:00,entry_1,exit_1
```

## 五、常见错误（导数据前自查）

| 问题 | 后果 | 怎么避免 |
|---|---|---|
| 出场时间早于或等于入场时间 | 该行报错，整个文件导入失败 | 只导「已离场」的完整记录 |
| 缺少车牌/入场/出场任一列 | 导入失败 | 按第二节的列名核对表头 |
| 车牌列是空的 | 导入失败 | 无牌车/临时车可填 `TEMP001` 之类的编号 |
| 还在场内没离场的车 | 无法计算停车时长 | 导出时过滤掉「在场车辆」 |
| 用 Excel 打开后另存成 xlsx | 系统只认 .csv | 另存为时选「CSV UTF-8」格式 |

## 六、车牌脱敏说明（合规）

- 系统拿到 CSV 后，默认把车牌换成 **不可逆的代号**（如 `P8A2F3C1D9E0`），原始车牌**不保存、不出现在任何页面和导出文件里**；
- 如果企业要求保留原始车牌做内部核对，请提前告知开发方，双方在**数据使用授权协议**里约定。

## 七、从停车场系统导出建议

大多数道闸/车牌识别系统都支持「进出记录报表导出」，建议导出字段选：
**车牌号 + 入场时间 + 出场时间 + 入场通道/出口通道**，导出时间范围选**最近一周**（数据量适中、能覆盖高峰和平峰）。
