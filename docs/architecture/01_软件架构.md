## 2. 核心类设计

### Spot
```python
@dataclass
class Spot:
    spot_id: str
    spot_type: Literal["STANDALONE", "TANDEM"]
    node_id: str           # 路网节点 ID
    stack_group_id: str
    depth: int
    position: tuple[float, float]
    is_occupied: bool = False
    occupied_by: Optional[str] = None
```

### Vehicle
```python
@dataclass
class Vehicle:
    vehicle_id: str
    arrival_time: float
    parking_duration: float       # 真实值 (oracle), 在线策略不可读
    estimated_duration: float     # 历史均值, 在线策略可用
    assigned_spot: Optional[str] = None
```

### ParkingLot
```python
class ParkingLot:
    spots: dict[str, Spot]
    stack_groups: dict[str, list[Spot]]
    road_network: RoadNetwork
    dist_matrix: dict[str, dict[str, float]]
    
    def get_available_spots(self, time: float) -> list[Spot]: ...
    def is_available(self, spot_id: str, time: float) -> bool: ...
    def get_blockers(self, spot_id: str, time: float) -> list[Vehicle]: ...
    def assign(self, vehicle: Vehicle, spot: Spot): ...
    def free(self, spot_id: str): ...
```

## 3. 数据流

```
config.json ──→ Config.load()
                    │
road_network.json ──→ RoadNetwork ──→ PathEngine (NetworkX) ──→ dist_matrix
                    │                                              │
demand.json ──→ Vehicle[] ──→ SimPy Engine ──→ Strategy.assign() ──→ ParkingLot ──→ EventLog
                                                                         │
                                                                         ▼
                                                                   Metrics.compute()
                                                                         │
                                                                         ▼
                                                                   metrics.json
```

## 5. 模块依赖方向

```
CLI → IO → Domain ← Routing
              ↓
         Simulation → Strategies → Evaluation
              ↓
         Optimization (CP-SAT)
```

**禁止反向依赖**：Domain 不依赖任何模块。策略不依赖仿真引擎。
