# 01 问题定义与假设

> 阶段A已批准路线：CP-SAT离线基准 → 在线贪心+动态缓冲位 → 多基线对照 → FCFS降级 → Dashboard推荐

---

## 1. 研究问题

在**普通独立车位与纵深车位混合**的停车场中，车辆陆续实时到达。系统在有限信息下，为每辆车即时分配车位，使得：

**分层目标（词典序）**：
1. **最大化需求满足率** — 尽可能不拒绝任何到达车辆
2. **最大化有效车位时空利用率** — 排除因纵深阻挡而不可用的时间
3. **最小化移位次数与移位距离** — 由纵深阻挡引发的额外挪车
4. **最小化等待时间与行驶距离** — 入位和离场效率

---

## 2. 系统边界

| 包含 | 不包含 |
|---|---|
| 停车场内部路网（入口→通道→车位） | 停车场外道路 |
| 普通车位 + 纵深车位统一建模 | 地面/地下区分（统一为路网） |
| 车辆到达→分配→入位→阻挡→移位→离场全流程 | 真实车辆转向/碰撞/感知 |
| 多策略在线决策与离线基准 | 定价/市场机制 |
| 仿真验证 + Dashboard推荐界面 | 真车调度执行 |
| 动态缓冲位（征用空闲车位） | 专用缓冲位 |

## 3. 关键概念定义

### 3.1 停车场

| 概念 | 定义 | 单位 |
|---|---|---|
| **路网** | 有向加权图 G=(N, E)，N 包含入口、出口、道路节点、车位节点 | — |
| **入口 entry** | 车辆进入停车场的节点，可多个（≥1）；默认入口为 `ENTRY`（或唯一入口），车辆需求可指定 `entry_id`，未指定走默认入口；Dijkstra 起点 | 节点 ID |
| **出口 exit** | 车辆离开停车场的节点，可多个（≥0）；默认出口为 `EXIT`（或唯一出口）；车辆需求可指定 `exit_id`；布局无出口节点时离场回该车入口 | 节点 ID |
| **通道** | 连接入口、车位和出口的可通行道路 | 边 |
| **边权重** | 两个相邻节点之间的行驶距离 | 米 |

### 3.2 车位

| 概念 | 定义 |
|---|---|
| **独立车位** | `stack_group_id` 唯一，`depth=1`，不被阻挡也不阻挡他人 |
| **纵深车位组 (Stack Group)** | 共享同一通道入口的一组纵深排列车位，组内按 depth 编号 |
| **depth** | `depth=1` = 最靠近通道；`depth=2` = 次靠近；... |
| **纵深车位** | `stack_group_id` 与同组车位相同，`depth>1` |
| **空闲** | `is_occupied=False`。depth=1 可直接分配；depth>1 要求所有外侧 depth 均空闲 |
| **缓冲位** | 无专用缓冲位。需要移位时，动态征用任意当前空闲车位（独立或 depth=1） |

### 3.3 阻挡与移位

| 概念 | 定义 |
|---|---|
| **阻挡 (Blocking)** | 车辆 A 位于 depth=k，车辆 B 位于 depth=j（j<k）。B 需要离场但 A 挡住了通道 → A 阻挡了 B |
| **移位 (Relocation)** | 阻挡车从原车位移动到缓冲位再返回（或留在缓冲位）的一次完整操作 |
| **一次移位计数** | 阻挡车从原车位出发到返回原车位（或新位置）计 1 次，距离=单程×2 |
| **连锁移位** | A 挡 B，B 又需要移位→A 先移出→B 再移出。逐步解决，每车移位独立计数 |

### 3.4 车辆与需求

| 概念 | 定义 | 来源 |
|---|---|---|
| **vehicle_id** | 唯一标识 | 仿真生成 |
| **arrival_time** | 车辆到达停车场入口的时间戳 | 仿真生成（双峰分布） |
| **parking_duration** | 真实停车时长（仿真中=真值） | 仿真生成（oracle） |
| **departure_time** | `arrival_time + parking_duration` | 导出值 |
| **estimated_duration** | 停车时长估计值 | 历史均值（当前不预测） |
| **assigned_spot** | 系统分配给该车辆的车位 | 决策输出 |

### 3.5 信息边界

| 场景 | 可见信息 |
|---|---|
| **离线 Oracle (CP-SAT)** | 全部车辆的 arrival_time + parking_duration（全信息） |
| **在线贪心** | 当前停车场状态 + 本车 arrival_time + estimated_duration（历史均值） |
| **Dijkstra-SA** | 同在线贪心 |
| **禁止泄露** | 未来的车辆到达、真实 parking_duration、离线最优解 |

### 3.6 不采用的概念（已否决）

| 概念 | 否决原因（阶段A） |
|---|---|
| ARIMA 时序预测 | 时间尺度错位，缺乏分钟级数据 |
| 随机森林"优化" | RF 不是组合优化器 |
| 由内到外顺序停放 | 消解优化问题本身 |
| 专用缓冲位 | 用户决定动态征用 |
| 强化学习策略 | 数据需求高、解释性差、风险高 |
| 预测+优化 | 无真实数据训练 |

## 4. 关键假设

| # | 假设 | 理由 |
|---|---|---|
| A1 | 停车场路网结构固定，仿真期间不变 | 物理事实 |
| A2 | 所有车辆尺寸统一（标准小轿车），每车占 1 个车位 | 简化，阶段C可评估敏感性 |
| A3 | 车辆在通道上单向行驶（按路网有向边） | 简化，避免对向冲突 |
| A4 | 移位操作中车辆行驶速度恒定（5 km/h） | 可计算移位时间 |
| A5 | 车位一旦分配不可更改，除非因阻挡触发被动移位 | 在线策略约束 |
| A6 | 车辆到达间隔和停车时长服从独立同分布（仿真中） | 仿真生成前提 |
| A7 | 缓冲位征用只发生在移位操作期间，完成后释放 | 动态缓冲位定义 |
| A8 | 不考虑充电桩、残疾人车位等特殊车位 | 聚焦核心问题 |

---

## 5. 时间与距离单位

| 量 | 单位 | 说明 |
|---|---|---|
| 距离 | 米 (m) | 所有路径和移位距离 |
| 时间 | 秒 (s) | 仿真时钟和事件时间戳 |
| 速度 | m/s | 距离÷速度=时间 |
| 利用率 | 无量纲 [0,1] | 占用时间÷总容量时间 |
| 满足率 | 无量纲 [0,1] | 成功分配÷总到达 |
