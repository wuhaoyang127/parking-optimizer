# 03 纵深阻挡与移位模型

---

## 1. 纵深车位形式化

### 1.1 数据结构

```
Spot {
    spot_id: str           # 如 "A12"
    type: "STANDALONE" | "TANDEM"
    position: (x, y)       # 坐标
    stack_group_id: str    # 纵深组ID；独立车位 = 唯一ID
    depth: int             # 1=靠通道，2,3,... 依次深入
    is_occupied: bool
    occupied_by: str|null  # vehicle_id
}
```

### 1.2 示例

```
Stack Group "G1":  [depth=1: G1-1] [depth=2: G1-2] [depth=3: G1-3]
                        ↑ 通道侧                  ↑ 最内侧

Stack Group "G2":  [depth=1: G2-1] [depth=2: G2-2]
```

独立车位就是 `stack_group_id` 唯一、`depth=1` 的特例。

## 2. 可用性判断

车位 $i$ 在时刻 $t$ **可分配** 当且仅当：

$$\text{available}(i, t) =
\begin{cases}
occ_i(t) = 0 & \text{if } depth(i) = 1 \\
occ_i(t) = 0 \land \forall j \in \mathcal{S}_{group(i)}, depth(j) < depth(i): occ_j(t) = 0 & \text{if } depth(i) > 1
\end{cases}$$

**含义**：depth=1 只需自己空；depth>1 需要所有外侧车位也空。

## 3. 阻挡判断

### 3.1 阻挡条件

车辆 $A$（停于车位 $i$）**阻挡** 车辆 $B$（停于车位 $j$）在时刻 $t$：

$$\text{blocking}(i, j, t) \iff
group(i) = group(j) \land depth(i) < depth(j) \land occ_i(t) = 1 \land occ_j(t) = 1$$

### 3.2 多级阻挡

若 `depth(i) < depth(j) < depth(k)`，且三者都被占用：
- $i$ 阻挡 $j$，也阻挡 $k$
- $j$ 阻挡 $k$
- $k$ 要离场 → 必须先移出 $i$ 和 $j$

**解除顺序**：从外到内（depth 从小到大）逐辆移出。

### 3.3 阻挡检测（离场时触发）

```
当车辆 v 到达 departure_time:
    spot = v.assigned_spot
    blockers = []
    遍历同组车位 j (depth(j) < depth(spot)):
        if occ_j(t) == 1:
            blockers.append(j)
    if blockers:
        触发移位流程(v, blockers)
    else:
        直接离场(v, spot)
```

## 4. 移位操作

### 4.1 一次移位操作的定义

```
relocation(blocker_vehicle, original_spot, buffer_spot, blocked_vehicle):
    1. blocker 从 original_spot → buffer_spot (行驶)
    2. blocked 从被挡车位 → 出口 (行驶 + 离场)
    3. blocker 从 buffer_spot → original_spot (返回，或留在 buffer_spot)
    
    计数: 1 次移位
    距离: d(original_spot, buffer_spot) + d(buffer_spot, original_spot) = 2 × d
```

### 4.2 缓冲位选择（动态征用）

```
select_buffer(t):
    候选 = {i ∈ S : occ_i(t) = 0 ∧ depth(i) = 1}  # 所有空闲独立或depth=1车位
    if 候选为空:
        return None  # 缓冲失败
    选择距离被阻挡车位最近（Dijkstra）的候选
    buffer_in_use.add(selected)
    return selected
```

### 4.3 多级阻挡的连锁移位

```
# 阻挡链: A(depth=1) → B(depth=2) → C(depth=3)，C 要离场
step 1: A 移入 buffer_1 → 释放 depth=1
step 2: B 移入 buffer_2 → 释放 depth=2
step 3: C 驶出 → 离场
step 4: B 从 buffer_2 → A原位置(depth=1)  # 归位或前移
step 5: A 从 buffer_1 → B原位置(depth=2)  # 归位或前移

移位次数: 2 (A移1次 + B移1次, C离场不算移位)
```

**优化规则**：
- 移位后车辆优先前移（填满外侧车位），减少未来阻挡发生
- 若 buffer 足够（≥阻挡链长度），可全移出后一次性释放

---

## 5. 缓冲位状态机

```
状态: FREE → RESERVED → OCCUPIED_BY_SHIFT → FREE

[FREE] ──(需要移位,无可征用)──→ [BUFFER_FAILED: 记录]
[FREE] ──(需要移位,征用成功)──→ [RESERVED]
[RESERVED] ──(移位车到达)──→ [OCCUPIED_BY_SHIFT]
[OCCUPIED_BY_SHIFT] ──(移位车离开)──→ [FREE]
```

---

## 6. 移位计数规则

| 事件 | 计数 |
|---|---|
| 阻挡车移出到缓冲位 → 返回 | **1 次移位** |
| 阻挡车移出 → 前移到其他空车位（不返回） | **1 次移位** |
| 被阻挡车直接驶出（无需移位时） | **0 次移位** |
| 多级阻挡 N 辆车需要移 | **N 次移位** |
| 移位距离 | 累计所有移位操作的往返距离 |

## 7. 未知离场时间的处理

**用户决定：暂不引入预测。当前使用历史平均停车时长作为 `estimated_duration`。**

- 贪心策略中 depth>1 分配决策使用 `t_arrival + estimated_duration` 作为"预计离场"
- 仿真开始时用固定默认值（如 2 小时），运行后可更新为仿真统计均值
- 不将真实 `parking_duration` 泄露给在线策略

---

## 8. 主动移位策略

**用户决定：暂不做主动移位。当前仅被动触发（被阻挡车离场时）。**

阶段C可评估：若缓冲位空闲且预测未来可能发生阻挡，是否提前预防性移位。

## 9. 极小可手工验证例（用于测试）

### 例1：仅有独立车位

```
车位: A1, A2, A3 (全部独立)
车辆: V1(arrival=0, duration=100), V2(arrival=10, duration=50)
路网: ENTRY → A1(5m), A2(8m), A3(12m)

贪心预期: V1→A1(最近), V2→A2
移位: 0
满足率: 2/2=1.0
```

### 例2：二深纵深 + 阻挡

```
车位: G1-1(depth=1), G1-2(depth=2)  # 同组纵深
车辆: V1(arrival=0, duration=200), V2(arrival=10, duration=50)
路网: ENTRY → G1-1(5m), G1-2(8m)

贪心预期: V1→G1-1(最近且depth=1), V2→G1-2(depth=2可分配,外侧G1-1已被占)
V2 离场(60s): 无阻挡(G1-1还在)
V1 离场(200s): 直接驶出
移位: 0
```

### 例3：阻挡触发移位

```
车位: G1-1(depth=1), G1-2(depth=2), 缓冲位候选=B1(独立,10m)
车辆: V1(arrival=0, duration=100), V2(arrival=10, duration=200)
路网: ENTRY → G1-1(5m), G1-2(8m)

贪心预期: V1→G1-1, V2→G1-2
V1 离场(100s): 直接驶出(G1-1在通道侧)
V2 离场(210s): 直接驶出
移位: 0

# 交换顺序来产生阻挡
车辆: V1(arrival=0, duration=200), V2(arrival=10, duration=50)
贪心预期: V1→G1-1, V2→G1-2
V2 离场(60s): V1 阻挡 V2 → V1 移入 B1 → V2 驶出 → V1 返回 G1-1
移位: 1次, 距离=2×d(G1-1,B1)
```
