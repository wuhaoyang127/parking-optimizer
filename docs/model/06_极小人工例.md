# 06 极小人工验证例

---

## 例1：只有独立车位（4车位，5辆车）

### 输入
```
车位: A1, A2, A3, A4 (全部 STANDALONE)
路网: ENTRY→A1(5m), A2(8m), A3(12m), A4(15m)

车辆:
  V1: arrival=0,   duration=200
  V2: arrival=10,  duration=80
  V3: arrival=20,  duration=50
  V4: arrival=30,  duration=100
  V5: arrival=200, duration=60
```

### 期望结果（贪心）
```
t=0:   V1→A1 (最近)
t=10:  V2→A2
t=20:  V3→A3
t=30:  V4→A4
t=90:  V3 离场, A3 释放
t=100: V2 离场, A2 释放
t=130: V4 离场, A4 释放
t=200: V1 离场, A1 释放 → V5→A1 (最近)
t=260: V5 离场
```

### 指标
| 指标 | 值 |
|---|---|
| 满足率 | 5/5 = 1.0 |
| 利用率 | (200+80+50+100+60) / (4×260) = 0.471 |
| 移位 | 0 |
| 有效利用率 | =利用率 (无阻挡) |

### 验证
✅ 无阻挡场景 → 贪心退化为最近路径 → 所有车获得最近可用车位

## 例2：两组二深纵深车位（4车位，5辆车）

### 输入
```
车位:
  G1-1(depth=1), G1-2(depth=2)  纵深组 G1
  G2-1(depth=1), G2-2(depth=2)  纵深组 G2

路网: ENTRY→G1-1(5m), G1-1→G1-2(3m); ENTRY→G2-1(8m), G2-1→G2-2(3m)

车辆:
  V1: arrival=0,   duration=300
  V2: arrival=10,  duration=100
  V3: arrival=20,  duration=50
  V4: arrival=30,  duration=200
  V5: arrival=80,  duration=60
```

### 期望结果（贪心）
```
t=0:   V1→G1-1 (最近,depth=1) ✓
t=10:  V2→G2-1 (depth=1) ✓
t=20:  V3: G1-2 被 V1 占外侧,但 G2-2 可用→V3→G2-2 (depth=2,G2-1被V2占)
t=30:  V4→G1-2 (G1-1被V1占,depth=2可用) ✓
t=70:  V3 离场(G2-2,depth=2): V2(G2-1)阻挡V3→V2移入缓冲位(B1)→V3驶出→V2回到G2-1
       移位: 1次
t=80:  V5→G2-2 (depth=2,G2-1被V2占) ✓
t=110: V2 离场(G2-1): 无阻挡,直接驶出
t=140: V5 离场(G2-2): 无阻挡(V2已走),直接驶出
t=300: V4 离场(G1-2): V1(G1-1)阻挡V4→V1移入缓冲位→V4驶出→V1回到G1-1
       移位: 1次
t=300: V1 离场(G1-1): 直接驶出
```

### 指标
| 指标 | 值 |
|---|---|
| 满足率 | 5/5 = 1.0 |
| 移位次数 | 2 |
| 移位涉及车辆 | V2, V1 |

### 验证
✅ 贪心正确优先分配 depth=1
✅ depth=2 在外侧被占时正确分配
✅ 离场时阻挡检测正确触发移位

## 例3：有缓冲位失败的边缘情况（3车位，3辆车，0可用缓冲位）

### 输入
```
车位:
  G1-1(depth=1), G1-2(depth=2)  纵深组 G1
  B1 (独立车位, 用作缓冲位但先被占)

路网: ENTRY→G1-1(5m), G1-1→G1-2(3m); ENTRY→B1(10m)

车辆:
  V1: arrival=0,   duration=200
  V2: arrival=10,  duration=300
  V3: arrival=20,  duration=50  # 短时停车,分配到B1
```

### 期望结果
```
t=0:   V1→G1-1
t=10:  V2→G1-2 (外侧V1被占,depth=2可用)
t=20:  V3→B1 (最后可用车位)
t=70:  V3 离场, B1 释放
t=200: V1 离场(G1-1): 直接驶出
t=300: V2 离场(G1-2): 无阻挡(V1已走),直接驶出
移位: 0
```

### 变例：V3 是长时停车
```
V3: arrival=20, duration=500  # 比V1,V2都长

t=20: V3→B1
t=200: V1 离场,需要移位?
       不需要! G1-1在depth=1,直接驶出
t=300: V2 离场(G1-2): 无阻挡(V1已走),直接驶出
t=520: V3 离场

移位: 0 (缓冲位B1未用于移位,而是作为普通车位被V3占用)
```

### 验证
✅ 动态缓冲位在不同需求下表现不同
✅ 无车位可征用时 → 降级处理（不崩溃）
