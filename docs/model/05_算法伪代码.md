## 1. 路网预处理

```
算法: PREPROCESS_NETWORK(road_network)

输入: G=(N, E, w: E→R+)  # 有向加权图
输出: dist[n1][n2]  # 所有节点对最短距离矩阵

for each source in N:
    dist[source] = DIJKSTRA(G, source)  # NetworkX: nx.shortest_path_length(G, source, target, weight='length')

复杂度: O(|N|·(|E|+|N|log|N|)), NetworkX 内部高效实现
```

## 2. 在线贪心主策略

```
算法: GREEDY_ASSIGN(v, t, state)

输入:
    v: Vehicle { id, arrival_time, estimated_duration }
    t: 当前仿真时间
    state: ParkingLot  { spots, road_network, dist_matrix }

输出: (assigned_spot_id, status) 或 (None, "rejected"/"waiting")

# === Step 1: 收集可用车位 ===
available = []
for spot in state.spots:
    if IS_AVAILABLE(spot, t, state):
        available.append(spot)

if not available:
    if len(waiting_queue) < MAX_WAIT and t - v.arrival_time < MAX_WAIT_TIME:
        waiting_queue.append(v)
        return (None, "waiting")
    return (None, "rejected")

# === Step 2: 按优先级分组 ===
group1 = []  # STANDALONE
group2 = []  # TANDEM depth=1
group3 = []  # TANDEM depth>1

for spot in available:
    if spot.type == "STANDALONE":
        group1.append(spot)
    elif spot.depth == 1:
        group2.append(spot)
    else:
        group3.append(spot)

# === Step 3: 同优先级内选择 ===
if group1 or group2:
    candidates = group1 if group1 else group2
    # 选路径距离最近的
    best = argmin(candidates, key=lambda s: dist[ENTRY][s.node_id])
elif group3:
    # 选内侧车预计离场最早的
    best = argmin(group3, key=lambda s: 
        state.spot_to_vehicle[s.inner_spot_id].arrival_time 
        + state.spot_to_vehicle[s.inner_spot_id].estimated_duration)
else:
    return (None, "rejected")

# === Step 4: 执行分配 ===
state.assign(v, best)
LOG_EVENT("parking_assigned", t, v.id, best.id)
return (best.id, "assigned")
```

## 3. 可用性判断

```
函数: IS_AVAILABLE(spot, t, state)

if spot.is_occupied:
    return False

if spot.depth == 1:
    return True

# depth > 1: 检查所有外侧车位
for outer in state.get_outer_spots(spot):  # depth < spot.depth 的同组车位
    if outer.is_occupied:
        return False

return True
```

## 4. 移位操作

```
算法: HANDLE_DEPARTURE_BLOCKED(v, t, state)

输入: 被阻挡车辆 v, 当前时间 t
输出: None (副作用: 状态变更 + 事件日志)

spot = v.assigned_spot
blockers = state.get_blockers(spot, t)  # 按 depth 从小到大排序的外侧占用车

# === 多级阻挡：从外到内逐辆移出 ===
for blk_vehicle in blockers:
    buffer = SELECT_BUFFER(t, state)
    
    if buffer is None:
        # 无可用缓冲位 → 降级
        LOG_EVENT("buffer_failed", t, blk_vehicle.id, v.id)
        # 降级处理: 等待直到有缓冲位可用
        schedule_retry(t + RETRY_INTERVAL, HANDLE_DEPARTURE_BLOCKED, v)
        return
    
    # 移位: 阻挡车 → 缓冲位
    dist_to_buffer = state.dist_matrix[blk_vehicle.assigned_spot.node_id][buffer.node_id]
    travel_time = dist_to_buffer / V_CAR
    state.shift_counts += 1
    state.total_shift_dist += dist_to_buffer * 2  # 往返
    
    # 执行移位
    state.move_vehicle(blk_vehicle, blk_vehicle.assigned_spot, buffer)
    LOG_EVENT("shift_start", t, blk_vehicle.id, 
              from=blk_vehicle.assigned_spot.id, to=buffer.id)

# === 被阻挡车离场 ===
state.free_spot(spot)
LOG_EVENT("departure_after_shift", t + travel_time, v.id)

# === 阻挡车归位（前移到最外侧空位） ===
for blk_vehicle in reversed(blockers):
    innermost_available = state.get_innermost_available(blk_vehicle.stack_group_id)
    if innermost_available:
        state.move_vehicle(blk_vehicle, buffer, innermost_available)
    else:
        state.move_vehicle(blk_vehicle, buffer, blk_vehicle.assigned_spot)  # 返回原位
    state.free_buffer(buffer)
    LOG_EVENT("shift_end", t + 2*travel_time, blk_vehicle.id, 
              final_spot=innermost_available or blk_vehicle.assigned_spot.id)

复杂度: O(blocker_count) ≤ O(|S|), 通常 ≤ 5
```

## 5. Dijkstra-SA 对照基线

```
算法: DIJKSTRA_SA_BATCH(vehicles_window, state, time_window_start)

输入: 窗口内已到达车辆列表, 当前状态, 窗口起始时间
输出: 分配方案 (vehicle_id → spot_id)

# Step 1: 最近路径初始化
solution = {}
for v in vehicles_window:
    available = [s for s in state.spots if IS_AVAILABLE(s, time_window_start, state)]
    solution[v.id] = NEAREST(available)  # 最近可用

# Step 2: SA 迭代优化
T = T_INIT
best_solution = solution
best_cost = EVALUATE(solution, state)

for iter = 1 to MAX_ITER:
    new_solution = MAKE_NEIGHBOR(solution, state)  # 随机交换或重分配
    new_cost = EVALUATE(new_solution, state)
    delta = new_cost - best_cost
    
    if delta < 0 or RANDOM() < exp(-delta / T):
        solution = new_solution
        if new_cost < best_cost:
            best_solution = new_solution
            best_cost = new_cost
    
    T = T * COOLING_RATE

return best_solution

# 目标函数 EVALUATE(solution):
#   cost = Σ[λ1 * path_dist + λ2 * wait_time + λ3 * block_risk + λ4 * unmet]
#   详见 Dijkstra-SA 原文档
```

## 6. 指标计算

```
算法: COMPUTE_METRICS(event_log, parking_lot, sim_duration)

输入: 事件日志列表, 停车场配置, 仿真总时长 T
输出: 指标字典

total_vehicles = count(VEHICLE_ARRIVAL events)
assigned = count(PARKING_ASSIGNED events)
rejected = total_vehicles - assigned

# 利用率
occupied_time = sum(event.duration for event in SPOT_ENTRY events)
spatial_util = occupied_time / (len(parking_lot.spots) * T)

# 有效利用率 (排除阻挡无用时间)
blocked_time = sum(duration for events where spot was blocked)
effective_util = (occupied_time - blocked_time) / (len(parking_lot.spots) * T)

# 移位
total_shifts = count(SHIFT_START events)
total_shift_dist = sum(event.distance for SHIFT_START events)

# 平均等待
wait_times = [w.wait_end - w.wait_start for w in WAIT events]
avg_wait = mean(wait_times) if wait_times else 0

# 行驶距离
total_drive_dist = sum(event.distance for SPOT_ENTRY events)

return {
    "satisfaction_rate": assigned / total_vehicles,
    "spatial_utilization": spatial_util,
    "effective_utilization": effective_util,
    "shift_count": total_shifts,
    "shift_distance": total_shift_dist,
    "avg_wait_time": avg_wait,
    "total_drive_distance": total_drive_dist,
    "rejected_count": rejected
}
```
