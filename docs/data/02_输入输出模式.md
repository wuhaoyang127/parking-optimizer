# 02 输入输出模式

## 数据流

```
road_network.json ──→ load_road_network() ──→ RoadNetwork ──→ PathEngine
                                                                    │
demand.json ──→ load_demand() ──→ Vehicle[] ──→ SimulationEngine ──→ events.jsonl
                      │                                                      │
config.json ──→ load_config()                                                │
                                                                             ▼
                                                                   compute_metrics()
                                                                             │
                                                                             ▼
                                                                      metrics.json
```

## 输入文件

| 文件 | Schema | 必填 |
|---|---|---|
| `road_network.json` | nodes[{id, type, x, y, spot_type?, stack_group_id?, depth?}], edges[{from, to, length}] | ✅ |
| `demand.json` | vehicles[{id, arrival_time, parking_duration, estimated_duration?}], metadata | ✅ |
| `config.json` | simulation, strategy parameters | ❌ 有默认值 |

## 输出文件

| 文件 | 格式 |
|---|---|
| `events.jsonl` | 每行一个 Event JSON |
| `metrics.json` | 单个 JSON 对象 |

## 字段来源标注规则

- **实测字段**: 标注 `source: measured`
- **仿真生成**: 标注 `source: synthetic`
- **事后真值**: 标注 `source: oracle` (在线策略不可读)
