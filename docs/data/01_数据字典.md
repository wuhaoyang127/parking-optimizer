# 01 数据字典与 Schema

---

## 1. 停车场路网 (road_network.json)

```json
{
  "nodes": [
    {"id": "ENTRY", "type": "entry", "x": 0.0, "y": 0.0},
    {"id": "EXIT", "type": "exit", "x": 50.0, "y": 0.0},
    {"id": "N01", "type": "road_node", "x": 5.0, "y": 0.0},
    {"id": "A01", "type": "parking_spot", "x": 8.0, "y": 2.0,
     "spot_type": "STANDALONE", "stack_group_id": "GA01", "depth": 1},
    {"id": "G1-1", "type": "parking_spot", "x": 20.0, "y": 2.0,
     "spot_type": "TANDEM", "stack_group_id": "G1", "depth": 1},
    {"id": "G1-2", "type": "parking_spot", "x": 24.0, "y": 2.0,
     "spot_type": "TANDEM", "stack_group_id": "G1", "depth": 2}
  ],
  "edges": [
    {"from": "ENTRY", "to": "N01", "length": 5.0},
    {"from": "N01", "to": "A01", "length": 3.0},
    {"from": "A01", "to": "N01", "length": 3.0},
    {"from": "N01", "to": "G1-1", "length": 12.0},
    {"from": "G1-1", "to": "G1-2", "length": 4.0},
    {"from": "G1-2", "to": "G1-1", "length": 4.0},
    {"from": "G1-1", "to": "N01", "length": 12.0}
  ]
}
```

**字段说明**：
| 字段 | 类型 | 含义 |
|---|---|---|
| nodes[].type | "entry"/"exit"/"road_node"/"parking_spot" | 节点类型 |
| nodes[].spot_type | "STANDALONE"/"TANDEM" (仅parking_spot) | 车位类型 |
| nodes[].stack_group_id | str (仅parking_spot) | 纵深组 ID |
| nodes[].depth | int (仅parking_spot) | 1=靠通道 |
| edges[].length | float | 边权重（米） |

## 2. 车辆需求 (demand.json)

```json
{
  "vehicles": [
    {"id": "V0001", "arrival_time": 0.0, "parking_duration": 3600.0,
     "estimated_duration": 7200.0}
  ],
  "metadata": {
    "total_vehicles": 150,
    "arrival_distribution": "bimodal_peak",
    "duration_distribution": "uniform_2400_21600",
    "seed": 42
  }
}
```

**字段来源标注**：
| 字段 | 来源 |
|---|---|
| arrival_time | 仿真生成 |
| parking_duration | 仿真生成（真实值，oracle） |
| estimated_duration | 历史均值（在线策略可见） |

**禁止**：在线策略读取 `parking_duration` 真实值。
