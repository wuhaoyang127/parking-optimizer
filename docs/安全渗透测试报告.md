整体安全状况良好：安全头、鉴权、输入校验、SQL 注入防护、登录限流、RLS、错误脱敏全部通过实测。发现并修复 2 项问题，另有 2 项需执行 SQL 迁移后生效。

## 发现并修复

### 1. 行程越权读取（IDOR）—— 已修

`GET /api/v2/journeys/{journey_id}` 之前不校验 session，任意 session 都能读到行程数据。

- 修复：加 `SessionIdHeader` + `require_driver_session`（错 session → 409）。
- 提交：`8223190`。

### 2. 研究端布局推送持有 service key（权限过大）—— 已修

研究端推布局之前用 service key 直连 `app_settings`，service key 权限过大（绕过 RLS）。

- 修复：新增 `push_driver_layout` / `list_driver_layouts` RPC（SECURITY DEFINER + token 权限校验），研究端只用 anon key；迁移未执行时自动回退 service key。
- 提交：`8223190` + `migrations/18_layout_push_rpc.sql`。
