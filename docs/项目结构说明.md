阶段 B 可以根据最终路线调整 `src/parking_opt/` 下的模块名称，但必须先更新架构文档和 `PROJECT_STATUS.md`，不能边编码边静默改变结构。

## 状态、计划和历史的职责

- `PROJECT_STATUS.md`：项目级当前状态、全局风险和唯一下一步；
- `docs/plans/`：当前阶段或复杂功能的详细计划；
- `docs/handoffs/`：阶段完成后的稳定交接摘要；
- `docs/archive/`：过期但需要追溯的文档；
- Git 历史：完整变更轨迹。

## 分层原则

- 领域模型不依赖界面；
- 动态策略只接收明确状态快照，不读取未来真值；
- 评估只消费标准日志和结果对象；
- 展示层调用稳定服务接口，不复制算法；
- 文件输入先经过 Schema 校验；
- 正式核心逻辑不得只存在于 `prototypes/` 或 Notebook。
